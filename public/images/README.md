# Photography

Openly licensed **stand-in** photography from Wikimedia Commons, used until EACH supplies its own images ([ADR 0005](../../docs/decisions/0005-interim-photography.md)). These photographs show East African places and plants. They are **not** EACH's work, sites or collections, and must never be captioned as if they were.

Every image is registered in `src/config/media.ts` with its alt text, caption and credit. The credit is shown wherever the image appears, as the licences require.

Files were downloaded as Commons renditions, then only resized and re-encoded (`sharp`, JPEG). They were not cropped, recoloured or otherwise edited. `object-fit: cover` crops them visually at display time.

Licence metadata was read from the Commons API (`extmetadata`) on 2026-10-19. The first five images were added in M02, the rest in M03.

The _Eclipta_ sheet (`herbarium-sheet-uganda.jpg`) is a specimen held by the Missouri Botanical Garden Herbarium and imaged at Kew. The sheet carries Kew's own "copyright reserved" scale bar. Commons and GBIF publish the image under CC BY 4.0, which is the licence relied on here.

The three herbarium sheets are used as **reference specimens** only and are captioned "Reference image, not an EACH specimen". Their label data (taxon, locality, date, collector) is transcribed from the Commons description, which cites each GBIF occurrence.
