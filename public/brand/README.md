Derived files:

| File | Description |
|---|---|

`BrandMark` uses the transparent PNG without a rectangular plate. A light CSS edge shadow keeps the dark portrait and lettering visible on dark and photographic surfaces. The original JPEG remains unchanged.

Rules:

- Use the original artwork or the approved background-only transparent derivative. Do not redraw, recolour, crop, re-typeset or distort the logo. That includes the portrait, globe, leaf and wordmark.
- Do not substitute a downloaded or AI-generated logo.
- An official vector (SVG) or transparent PNG master is still preferred: this derivative retains the JPEG's resolution and edge quality. Request a master from EACH; do not trace the JPEG.
- Bitwiire Herbarium Cafe assets, if ever used, must be stored separately and labelled as partner assets.
