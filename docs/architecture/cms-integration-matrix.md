# CMS-to-public integration matrix

Where every public route and section gets its content, how it is edited, published and invalidated, and how it is verified. Decisions: [ADR 0007](../decisions/0007-cms-editorial-workflow.md), [0011](../decisions/0011-content-revisions.md), [0012](../decisions/0012-cms-page-registry-seo-and-settings.md).

**Legend**

- **Workflow D→R→P→A**: Draft → In review → Published → Archived, with pending revisions for published items (ADR 0011). Settings are live on save (administrators only, audited).
- **Tags**: `"use cache"` tags expired with `updateTag` when content goes live, changes while live, or leaves the site (`src/lib/cache-tags.ts`). `content:` prefix omitted below.
- **Code-owned**: designed copy and presentation that stays in code by decision (ADR 0012), not institutional data.
- **Verified by**: `U` = `tests/unit/pages.test.tsx` (every route renders from the seeded database with one h1, metadata, indexing rules); `I` = `tests/integration/*.test.ts`; `E` = `tests/e2e/admin.spec.ts`. Results are in the [M04 CMS verification report](../audits/M04-cms-verification.md).

## Admin route mapping (brief → implemented)

The brief's target routes are capabilities; existing coherent conventions were kept.

| Brief                                                      | Implemented                                                                                   |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `/admin/programs…`                                         | `/admin/programmes…` (British English, as in the rest of the site)                            |
| `/admin/<type>/[id]/edit`                                  | `/admin/<type>/[id]` (editor and workflow panel on one page)                                  |
| `/admin/audit-logs`                                        | `/admin/audit`                                                                                |
| `/admin/reviews`                                           | `/admin/reviews` (new: items in review and pending changes)                                   |
| `/admin/settings/{branding,contact,navigation,footer,seo}` | Same (new); `/admin/settings` is the overview                                                 |
| `/admin/pages/[id]/edit`                                   | `/admin/pages/[id]` (registry-driven editor: homepage sections, landing headers, policy text) |
| Previews                                                   | `/admin/preview/{pages,projects,articles}/[id]`, showing pending changes when present         |
